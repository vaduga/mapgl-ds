# Default build configuration by Grafana

This directory mirrors the configuration generated by `@grafana/create-plugin`.
Project-specific extensions, including the synchronous inlined WASM bridge,
belong in the root `rspack.config.js` and `webpack.config.js` files.

The canonical `src/plugin.json` manifest and `src/README.md` catalog page are
copied into `dist/vaduga-mapgl-datasource/` together with production source maps.
