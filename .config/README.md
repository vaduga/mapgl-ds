# Default build configuration by Grafana

This directory mirrors the configuration generated by `@grafana/create-plugin`.
Project-specific extensions belong in the root `rspack.config.js` and
`webpack.config.js` files.

The datasource intentionally keeps `plugin.json` at the repository root and
packages into `dist/vaduga-mapgl-datasource/`; the shared bundler helpers account
for those established project conventions.
